# Herdr 설치 및 설정 기록

이 저장소는 Herdr 데스크톱 앱의 설치, 설정, 모드 관리를 수행하고 그 과정을 기록하는 작업 공간입니다. 다른 환경에서도 설정을 재현할 수 있도록 적용 파일, 원본 버전, 변경 이유와 검증 결과를 함께 관리합니다.

## 문서

- [문서 안내](docs/README.md): 읽는 순서와 기록 원칙을 설명합니다.
- [설치와 재현](docs/setup.md): 확인한 환경, 설치 경로와 재현 순서를 정리합니다.
- [통계 전송과 업데이트 설정](docs/configuration.md): 수정할 파일과 설정값, 적용 범위를 설명합니다.
- [2026-11-13 작업 기록](docs/history/2026-11-13.md): 기존 세션에서 수행한 작업과 현재 확인 결과를 정리합니다.
- [모드 관리](mods/README.md): 외부 원본과 로컬 설정의 관리 규칙을 설명합니다.
- [Tmux prefix](mods/local/tmux-prefix/README.md): 단축키와 앱에 적용하는 방법을 설명합니다.

## 구성

```text
docs/          # 설치·설정 절차와 작업 기록
mods/sources/  # 외부 원본 Git submodule
mods/local/    # 직접 관리하는 설정과 수정본
AGENTS.md      # 이 작업 공간의 에이전트 작업 지침
CLAUDE.md      # AGENTS.md 참조
```

실제 앱과 개인 설정은 사용자 홈 디렉터리에 설치됩니다. 이 저장소에서는 재현에 필요한 문서와 설정 조각을 관리하며, 실행 로그나 개인 상태 파일은 보관하지 않습니다.
