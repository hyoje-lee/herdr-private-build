# 설치·설정 문서

이 폴더에는 Herdr 설치와 설정을 다시 수행하는 데 필요한 절차와, 실제 수행한 작업의 근거를 기록합니다. 현재 기준은 2026-11-13에 확인한 Linux 데스크톱 환경입니다.

## 읽는 순서

| 문서 | 내용 |
| --- | --- |
| [설치와 재현](setup.md) | 확인한 버전, 설치 경로, 새 환경에서 수행할 순서를 설명합니다. |
| [통계 전송과 업데이트 설정](configuration.md) | 통계 비활성화, Dash 실행 항목, 업데이트 우회 설정을 설명합니다. |
| [모드 관리](../mods/README.md) | 원본 submodule과 로컬 파일의 관리 원칙을 설명합니다. |
| [Tmux prefix](../mods/local/tmux-prefix/README.md) | 단축키 설정과 적용·검증 절차를 설명합니다. |
| [2026-11-13 작업 기록](history/2026-11-13.md) | 기존 세션의 설치·설정 작업과 문서 작성 시점의 대조 결과를 정리합니다. |

## 기록 원칙

- 설치하거나 설정을 바꾸면 관련 절차 문서와 `history/YYYY-MM-DD.md`를 함께 갱신합니다. 날짜와 시각은 별도 표시가 없으면 한국 시간입니다.
- 작업 기록에는 목적, 앱·코어 버전, 원본 커밋, 변경 경로와 핵심 설정값, 백업 위치, 검증 결과와 미확인 항목을 적습니다.
- 과거 세션에서 확인한 사실과 이번에 직접 확인한 사실을 구분합니다. 가능하면 세션 ID와 이벤트 번호, 버전을 고정한 공식 소스 링크를 남깁니다.
- 계획만 세운 작업은 완료로 적지 않습니다. 설정 파일 일치, 앱 로드 성공, 실제 GUI 동작 검증도 구분합니다.
- 모드별 세부 설명은 해당 모드의 README에 유지하고 여기에서는 연결합니다.
- 비밀값, 전체 대화 기록, 개인 설정 전체, 앱 상태와 로그는 복사하지 않습니다. 백업은 앱 설정 디렉터리 등 저장소 밖에 보관합니다.

## 남은 검증

Tmux prefix 설정은 앱에 적용됐고 로드 오류도 없지만, 실제 키 입력을 이용한 전체 동작 검증은 완료되지 않았습니다. [모드별 검증 항목](../mods/local/tmux-prefix/README.md#적용-순서)에 따라 확인한 뒤 작업 기록을 추가합니다.
