## 기록 원칙

- 설치나 설정 방법이 바뀌면 해당 절차 문서를 갱신하고, 해당 장비에서 수행한 작업은 `local-history/YYYY-MM-DD.md`에 기록합니다.
- 다른 환경에서 필요한 기준 버전, 설정 경로, 명령, 변경 이유와 확인 방법을 기록합니다. 원본 커밋은 Git submodule로 고정하고, 설명의 근거는 버전을 고정한 공식 소스로 연결합니다.
- 개인 경로, 세션 ID, 로컬 백업 위치, 스테이징 상태나 특정 장비의 실행 결과는 공유 문서 대신 로컬 기록에 남깁니다. 필요한 근거만 요약합니다.
- 호환성 제한과 미검증 동작은 명시합니다. 설정 파일 일치, 앱 로드 성공, 실제 GUI 동작 검증을 구분합니다.
- 모드별 세부 설명은 해당 모드의 README에 유지하고 여기에서는 연결합니다.
- 비밀값, 전체 대화 기록, 개인 설정 전체, 앱 상태와 로그는 복사하지 않습니다. 백업은 앱 설정 디렉터리 등 저장소 밖에 보관합니다.

## 로컬 기록 보관

`local-history/`는 `.gitkeep`만 Git으로 추적하고 나머지 내용은 루트 `.gitignore`로 제외합니다. 다른 환경에서는 같은 폴더에 해당 장비의 작업 기록을 새로 작성합니다. 기록을 강제로 스테이징하지 않습니다.

기존 기록을 정리할 때에는 내용을 삭제하지 않고 이 폴더로 옮깁니다. Git에서 제외된 기록은 clone이나 pull로 복원되지 않으므로 필요한 백업은 별도로 유지합니다. 공유 문서에는 로컬 기록 파일로 연결되는 링크를 넣지 않습니다.

## 적용 후 검증

Tmux prefix 설정은 적용한 환경에서 [모드별 검증 항목](../mods/local/tmux-prefix/README.md#적용-순서)에 따라 실제 키 입력까지 확인합니다. 초기 로드 성공만으로 모든 단축키의 동작을 보장하지 않습니다.
